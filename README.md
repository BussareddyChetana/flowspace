# 🌿 FlowSpace AI

**Your personal AI space to plan tasks, organize your day, and reflect on your thoughts.**

FlowSpace AI is a lightweight, browser-based AI assistant designed to help you manage your tasks and express your thoughts in a simple, supportive environment. It provides two modes: **Plan Your Day** and **Vent & Reflect**.

## ✨ Features

### 📅 Plan Your Day
- Enter your tasks and daily goals.
- Generate an organized schedule with priorities and suggested time slots.
- Break your day into manageable tasks.
- Export your plan for convenient use.

### 💭 Vent & Reflect
- Express your thoughts and feelings in text.
- Receive an AI-generated reflection and gentle reframe.
- Get one small, practical next step.
- Use voice input for a more natural experience.

### 🎙️ Voice Support
- Record voice notes directly in the browser.
- Supports voice input in both planning and reflection modes.
- View the transcript of your recorded note when supported by the application.

### 🎨 Simple User Interface
- Clean, responsive design.
- Separate modes for planning and reflection.
- Works in modern web browsers.

## ⚙️ Setup and Usage

1. Open the live website or download the repository.
2. Configure the Gemini API integration as required by the application.
3. Enter your tasks in Plan Your Day mode or share your thoughts in Vent & Reflect mode.
4. Review the generated response and use the available export options.

## 🔑 API Configuration

FlowSpace AI uses the Google Gemini API to generate AI-powered responses.

Configure the API settings in `static/config.js` according to the application's implementation.

**Security note:** GitHub Pages hosts static files, so any API key included in frontend JavaScript can be viewed by visitors. Do not publish a private API key in a public repository. For a production deployment, use a backend API that keeps the key in server-side environment variables.
